PR Reviewer browser extension: privacy

The extension reviews GitHub pull requests from a side panel. It has no server of its own and collects no analytics.

What is sent where

  • GitHub (github.com and api.github.com, or an Enterprise host you add): requests to read the pull request you review, and, only when you press Post, to post your review and summary comment.
  • Your AI provider (Anthropic, OpenAI, the compatible endpoint you choose, or Ollama, which runs on your own computer): the pull request's diff and file contents, with detected secrets removed first.
  • OSV (api.osv.dev): names and versions of packages the pull request adds or upgrades, to look up known vulnerabilities.
  • Your team's Web App or pr-reviewer on this computer, only if you connect one: the pull request's link, which findings to post and your edits. That pr-reviewer then talks to GitHub and the AI with its own credentials; the extension does not send them the diff itself.
  • Nothing is sent anywhere else.

What is stored in your browser

  • If you connect a Web App or this computer: its address and a token for it, encrypted the same way. Disconnect any time in Settings; revoke the token on the Web App or with pr-reviewer serve --unpair.
  • Your GitHub token and AI key, encrypted at rest with a key that cannot be exported, in the extension's own storage, which web pages cannot read. Remove them any time in Settings.
  • The last review of up to 50 recent pull requests, including short code excerpts, so the panel can show them again. Clear them any time in Settings.

What is never done

  • Nothing is posted to GitHub unless you press Post. The extension never approves a pull request.
  • The extension does not read GitHub's pages; it only places one button in the pull request header and reads the page's colour mode.
